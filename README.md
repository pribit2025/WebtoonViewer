# 웹툰 뷰어 (Galaxy / Android)

로컬에 저장한 웹툰(작품폴더/화별 zip·cbz)을 세로 연속 스크롤로 보는 Android 앱.
Aeonss/WebtoonReader(MIT, Python/Tkinter PC용)의 라이브러리 구조와 기능 컨셉을 바탕으로 Android(Kotlin)용으로 새로 구현.

## 기능
- 웹툰 모드: 화 안의 모든 이미지를 이음새 없이 세로 연속 스크롤
- 좌우 여백 조절: 리더 화면 가운데 탭 > 좌우 여백 슬라이더(0~40%) — 보던 위치 유지
- 읽은 화 색상 변경: 읽음=회색(읽음 ✓), 보는 중=파란색+진행률, 마지막 본 화=좌측 파란 막대
- 이어보기 버튼, 읽던 위치 자동 저장/복원
- 끝까지 보면 자동 읽음 처리, 화 끝에 '다음 화' 버튼, 다음 화 미리 압축해제
- 길게 눌러 읽음/안읽음, '이 화까지 모두 읽음' 처리
- 진행 위치 스크러버, 이전/다음 화 버튼
- 배경색(검정/회색/흰색), 볼륨키 스크롤, 상하 탭 스크롤(옵션)
- 작품 목록: 읽은 화 수/진행 막대, 최근 읽은 순·이름순 정렬
- 화면 꺼짐 방지, 전체화면, 세로로 아주 긴 이미지 분할 디코딩(메모리 안전)
- 한글 파일명 zip(CP949) 지원, 이미지 폴더 형태의 화도 지원

## 라이브러리 구조
```
라이브러리 폴더/
├── 작품A/
│   ├── 001화.zip
│   ├── 002화.cbz
│   └── ...
└── 작품B/
    └── ...
```
지원 이미지: jpg, jpeg, png, webp, gif(첫 프레임), bmp, avif·heic(기기 지원 시)

## APK 빌드 방법

### 방법 1. GitHub Actions (PC에 개발도구 설치 불필요)
1. GitHub에서 새 저장소(Private 가능) 생성
2. 이 폴더 전체를 업로드 (웹에서 Add file > Upload files 로 드래그, `.github` 폴더 포함 확인)
3. 저장소의 Actions 탭 > "Build APK" 실행 완료(약 3~5분) 대기
4. 실행 결과 하단 Artifacts > `WebtoonViewer-apk` 다운로드 → 압축 풀면 `app-debug.apk`

### 방법 2. Android Studio
1. Android Studio에서 이 폴더 Open
2. Build > Build App Bundle(s)/APK(s) > Build APK(s)
3. 결과: `app/build/outputs/apk/debug/app-debug.apk`

## 갤럭시에 설치
1. APK를 휴대폰으로 복사(카카오톡 나에게 보내기, USB, 구글 드라이브 등)
2. 내 파일 앱에서 APK 실행 → "출처를 알 수 없는 앱 설치" 허용 → 설치
3. 앱 실행 > 라이브러리 폴더 선택 (한 번만 지정하면 계속 기억)

## 사용법
- 리더 화면 가운데 탭: 메뉴 표시/숨김
- 메뉴: 진행 위치 / 이전·다음 화 / 좌우 여백 / 배경 / 볼륨키 / 상하 탭 스크롤

## 참고
- 디버그 서명 APK로, 개인 사용 목적
- 압축 해제 캐시는 현재·이전·다음 화만 유지(앱 캐시 폴더)
- 열람 기록은 "작품폴더명/화 파일명" 기준이라 폴더를 다시 선택해도 유지됨(이름 변경 시 초기화)
